📖 Ingestion Guidelines & Schema Specs

The Ingestion Engine validates the full educational hierarchy and generates relational database records in a single transactional cascade:

  • # Unit Title: Primary course unit entity (stored with category="Global")
  • ## Module Title: Major curriculum block belonging to unit
  • ### Topic Title: Thematic subject area inside module
  • #### Subtopic Title: Granular lesson node (tracks completion & progress)
  • - Objective: Concrete learning objectives evaluated by Socratic AI & Quiz generation
Note on Cloning: Global units can be cloned directly into any student's active semester curriculum via /api/units/library/add/{unit_id}.
